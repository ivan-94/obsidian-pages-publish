# 中英文、Unicode、emoji 与一个刻意很长很长的标题组合

Typography should remain calm when 中文、English、数字 2026、符号 α/β/γ 与 emoji 🧭🌊🧪 出现在同一段落。

## Long tokens

一个不可随意断开的标识符：`pages-publish-theme-brutalist-integrity-verification-boundary`。

一个较长 URL 形态但不发起远程请求的代码样本：

```text
https://example.invalid/a/very/long/path/that/exists/only/as/code/not-as-a-runtime-resource
```

## 标点密度

“引号”、（括号）、《书名号》、破折号——以及省略号……都应该获得自然字距；English punctuation, meanwhile, should not look detached.
